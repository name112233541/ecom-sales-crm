# 工作记忆索引

每次开始新任务前，先读这个文件，再查相关任务和技能记录。

## 任务前检查

1. 读 `memory/INDEX.md`
2. 查 `memory/tasks/` 里有没有做过同类任务
3. 查 `memory/skills/` 里有没有可复用步骤或脚本
4. 查 `memory/decisions.md` 里有没有已经确认过的决定
5. 不确定的地方先问，不猜

## 目录

- `tasks/`：任务记录、结果、遗留问题
- `skills/`：可复用操作步骤、脚本说明、工具评估
- `decisions.md`：已经确认过的长期决定

## 硬性规则

- 不向用户索要密码、短信验证码、Cookie、API Key
- 需要登录时，由用户在自己的浏览器完成
- 安装 GitHub 项目或系统工具前，先说明用途、依赖、权限、风险和卸载方式，并征得用户同意
- 没弄懂业务目标、数据范围、成功标准之前，不要求用户配合操作
- 不把公司客户数据、聊天记录、代码带到个人项目
- 完成任务后更新 `tasks/`，把可复用部分整理到 `skills/`
