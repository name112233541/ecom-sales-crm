# 2026-11-04 团队协作：电商 CRM 变现方向

## 团队角色

| 角色 | 职责 | 不负责 |
|---|---|---|
| Lead | 定目标、拆任务、验收、权限控制、对用户沟通 | 不代替客户做登录/收款/签约 |
| market-analyst | 客户画像、痛点、付费意愿、竞品、定价、获客渠道、7 天验证 | 不做产品功能、不写销售文案、不写代码 |
| product-builder | 产品范围、功能取舍、部署方式、交付流程、验收标准、工时、backlog | 不定价、不写销售话术、不改代码 |
| sales-strategist | 卖点、报价、落地页、私信、异议处理、获客行动表 | 不做市场研究、不做产品设计、不发布/联系客户 |
| delivery-qa | 上线检查、启动会、验收、bug 分级、数据安全、复盘、退款/终止 SOP | 不写代码、不做销售、不接触真实客户数据 |

## 已确认的变现决定

1. 首单不卖 SaaS/多用户系统，先卖人工服务：**7 天成交漏损快诊**。
2. 价格：前 3 个验证名额 1,999 元；标准价 2,999 元；100% 预付；资料齐全且访谈完成后 3 个工作日内交付。
3. 目标客户：3～10 人优先、1～5 名销售/客服、高客单或需人工多次跟单、靠微信+Excel/ERP、老板能拍板的中小电商团队。
4. demo 只用于演示和可视化，不录真实客户数据，不承诺部署、多用户、账号、权限、同步、跨设备。
5. 升单：2 周跟进机制落地陪跑 6,999～9,999 元，优先在客户现有 Excel/飞书/企微中配置；4 周复盘托管 4,999 元/4 周，不自动续费。
6. 当前 localStorage 版本只能定位为“单浏览器单数据集演示/单工作台验证”，不能对外宣称是多人协作 CRM。
7. 7 天验证通过标准：至少 1 笔实收；至少 3 个合格线索；首单交付不超过 8 小时；口头认可不算通过。
8. 不做爬虫、自动私信、非官方平台接口；不承诺 GMV/转化率；数据脱敏。

## 已知风险

- 最大风险是销售承诺超过产品能力：把单浏览器 demo 说成多人云端 CRM。
- 数据存在浏览器 localStorage，清缓存/换设备/换浏览器可能丢失；必须每日 JSON 备份。
- 无登录、无权限、无审计；只适合脱敏数据、单工作台、1～3 人轮流使用。
- 无原生 CSV 导入；首版靠交付人员协助转换 + JSON 恢复，客户不能自助上传 CSV。

## 下一步

1. 将首单服务整理成一页式销售页和报价单。
2. 生成客户版《当前系统能力边界》。
3. 生成 7 天诊断访谈提纲、数据脱敏模板、验收表。
4. 由用户本人执行获客和收款；助手不代替登录、发布、联系客户或收款。
