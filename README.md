# 电商销售台 · Ecom Sales CRM MVP

一个本地运行的电商销售/客服跟进单页应用，先把这条主流程跑通：

> 线索 → 客户 → 跟进 → 订单 → 成交复盘

这是第一版 MVP，不是完整商城、ERP 或企业微信机器人。

## 功能

- 工作台：客户总数、待跟进、本月有效订单、本月成交额
- 销售漏斗：全部线索 → 已触达 → 有意向 → 已报价 → 已成交
- 客户管理：新增/编辑/删除、搜索、按状态和来源筛选
- 客户详情：联系方式、预算、标签、备注、规则版下一步建议
- 跟进记录：沟通方式、沟通内容、下次跟进日期
- 跟进提醒：逾期、今天、未来 7 天分组
- 订单：待付款、已付款、已发货、已完成、已退款
- 数据：localStorage 本地保存、JSON 备份/恢复、客户 CSV 导出
- 演示数据：首次打开自动生成，可在侧边栏重置

## 运行

### 最简单

直接双击 `index.html`，用 Chrome / Edge 打开。

### 本地静态服务器（推荐）

在项目目录执行：

```bash
python -m http.server 8080
```

然后打开：

```text
http://localhost:8080
```

## 数据说明

- 数据保存在浏览器 `localStorage`，键名：`ecom_crm_mvp_v1`
- 换浏览器、清理浏览器数据后，数据不会自动同步
- 重要数据请用“导出 JSON 备份”保存
- JSON 导入会覆盖当前浏览器数据

## 当前边界

- 单机版，无登录、无多用户、无服务端
- 不包含抖音爬虫、自动私信、矩阵号、企业微信外挂
- 不包含真实支付、物流、发票、库存
- 不适合直接存真实客户敏感信息；生产化前需要补权限、审计、加密和隐私合规

## 后续可以加

- 客户 CSV 导入
- 多销售账号和权限
- 企业微信/平台官方线索接口
- AI 跟进总结（需要服务端 API Key，不能把密钥放前端）
- 订单回款报表、退款原因分析
- 自动生成日报/周报
- 数据导出为 Excel
